User Manual for Asset Verification Module on the Fleet Information System

 

Purpose of Program

The Purpose of the Asset Verification program lies within the need for a uniform program for data capturing related to verification of vehicles and the subsequent analysis of the outcome of the matters.

 

Term/ Field Analysis

The detail of the required data fields are in most cases self-explanatory but will however be specified.

 

It is the assumption that each and every user of the GFLEET Administrative functions on the Fleet Information System has received on the job training in the specified field that pertains to his/ her division.

 

Reg Number

Type in the GG number of the vehicle you wish to add.

Submit Button

Sends the GG number you entered in Reg Number text box field to the database to retrieve the vehicles information.

Menu Button

Returns back to the menu options.

Province

Select the province where the vehicle is situated. (required field)

Department name

Displays the name of the department (non editable field)

Site Name

Displays the name of the site (non editable field)

Responsible Manager

Displays the name of the person responsible for the vehicle (required field)

Tel. No

Displays the telephone number of the responsible person (required field)

Fax No

Displays the fax number of the responsible person (required field)

Vehicle Reg. No

Displays the GG number of the vehicle (non editable field)

Vehicle Make

Displays the make of the vehicle (non editable field)

Vehicle Color

Displays the color of the vehicle (non editable field)

Vehicle Model

Displays the model of the vehicle (non editable field)

Mobitrack Fitted

Select whether the vehicle is fitted with a tracking device or not.

Petrol Card

Select whether the vehicle has a petrol card or not.

Lamination

 

Tyre Bands

 

Barcode

Select whether the vehicle has a barcode or not.

Logbook

Select whether the vehicle has a logbook or not.

Gearlock

Select whether the vehicle has a gear lock or not.

Radio

Select whether the vehicle is fitted with a radio or not.

Car Keys

Select whether the vehicle has a set of keys.

License Expiry Date

Displays the expiry date of the license disc (non editable field)

Barcode Number

Displays the barcode number. If you selected Yes in the barcode drop down box then this field (Barcode Number) becomes non editable. If you selected No in the barcode drop down box then this field (Barcode Number) becomes editable.

Vehicle Engine Number

Displays the vehicles engine number (non editable field).

Vehicle Chassis Number

Displays the vehicles chassis number (non editable field).

Current KM (from vehicle)

The user enters the latest kilometers of the vehicle when it was last verified at Government Garage.

Last Verified

The user enters the date when the car was last verified at Government Garage.

Comment

Essential information that must be taken into consideration
