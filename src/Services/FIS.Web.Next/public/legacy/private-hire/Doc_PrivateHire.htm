User Manual for Private Hire Section on the Fleet Information System

 

Purpose of Program

The Purpose of the Private Hire program lies within the need for a uniform program for data capturing of private hire services.

Term/ Field Analysis

The detail of the required data fields are in most cases self-explanatory but will however be specified.

 

It is the assumption that each and every user of the GGMT Administrative functions on the Fleet Information System has received on the job training in the specified field that pertains to his/ her division.

 

Registration Number

The registration number of the hired private vehicle.

Make & Model

Manufacturer and model of the vehicle.

Site

The Branch of GGMT the vehicle has made the arrangements

Contracted to

The site of the end user of the specified vehicle.

Contractor

The company the vehicle has been hired from.

Year Manufactured

The year the vehicle has been manufactured.

Bank code

The code allocated from the bank to the model

Colour

Primary Colour of the vehicle

Tank Capacity

Volume of the fuel tank.

Engine Number

Unique engine number assigned by the manufacturer.

Chassis Number

Unique chassis number assigned by the manufacturer.

Fuel Card Number

PAN of the Fuel Card.

Fuel Card Receiver

Identification of the person that received the fuel card.

Take-On Date

Date the vehicle has been taken onto the system.

KM Tariff

The specification of the vehicle’s Kilometer tariff.

Hourly Tariff

The specification of the vehicle’s Hourly tariff.

Daily

The specification of the vehicle’s daily tariff.

Return Date

The expected date the vehicle will be returned.

Return Odometer

Kilometer reading upon return.

Submit

Submits the information to the data base.
