User Manual for Taxis Section on the Fleet Information System

 

Purpose of Program

The Purpose of the Workshop program lies within the need for a uniform program for data capturing of all workshopservices.

 

Term/ Field Analysis

The detail of the required data fields are in most cases self-explanatory but will however be specified.

 

It is the assumption that each and every user of the GGMT Administrative functions on the Fleet Information System has received on the job training in the specified field that pertains to his/ her division.

Fields that is seen on more than one page will not be duplicated in the Term/ Field analysis, as the meanings/ definitions would stay within similar parameters.
