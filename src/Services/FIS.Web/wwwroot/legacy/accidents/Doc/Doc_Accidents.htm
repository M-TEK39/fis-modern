User Manual for Accidents Section on the Fleet Information System

 

Purpose of Program

The Purpose of the accidents program lies within the need for a uniform program for data capturing of vehicles that has been involved in accidents and the subsequent outcome of the accidents.

 

Term/ Field Analysis

The detail of the required data fields are in most cases self-explanatory but will however be specified.

 

It is the assumption that each and every user of the GGMT Administrative functions on the Fleet Information System has received on the job training in the specified field that pertains to his/ her division.

 

Accident Maintenance

The capturing/ updating of data for vehicles that has been involved in accident.

GG/ GP Number

Registration number of vehicle that has been involved in the Accident.

Submit

Submits the information to the database.

MOD

Allows user to go and edit or modify previous entries onto the system.

Add

Add new incident to that is not related to any other previous accident on the system.

Accident Date

Date the specified vehicle was involved in an accident.

Accident Time

Time of the specified Accident.

GG CAR Km

Odometer reading of the vehicle involved in the accident.

Date Updated

Specification of the last date any updates has been made to the data related to this vehicle/ accident.

Accident Description

Description of the damage to the Government Vehicle.

Accident Category

Identification of accident type.

Notify HQ

Indication whether Head Office has supplied with all relevant documentation.

Notify Date HQ

Date documentation pertaining to this matter has been forwarded to Head Office

GG Driver Fault

Indication whether the GG driver was responsible for the accident or not.

GG Driver Name

Name of the driver of the GG vehicle at the time of the accident.

GG Driver ID Number

ID Number of the Driver of the GG vehicle at the time of the accident.

Site

Site where vehicle and driver is stationed.

Trip Authority

Indication whether of not the person was in possession of a valid Trip Authority for the specified vehicle at the Time of the Accident

Transport Officer

The Transport Officer of the user department responsible for the specified vehicle.

Transport Officer Tel.

The contact telephone number of the relevant Transport Officer.

GG Reference

The unique reference number issued by GGMT to this matter.

Case Number

The reference number as issued by the South African Police Service allocated to this accident.

GG Car Damage

Damage Value

GG Damage Desc

Description of the damage to the GG vehicle.

Death

Indicate whether any person was killed as a result of the accident.

Injured

Indicate whether any person was injured as a result of the accident.

Private Car Registration+

Registration number of the private vehicle with which the GG vehicle was involved with in this accident.

Private Party Name

Identification of the private party being the driver of the private vehicle.

Private Car Damage

Damage Value

Claim Received

Indication whether or not a claim has been received.

Claim amount

The amount of the claim that has been received.

File Close Date

Date the file was closed.

Receive Docs. For relieve?

Indicating if all required documentation has been received.

Notes

Any additional information relevant to this matter.

Submit

Submitting the data to the data base.
