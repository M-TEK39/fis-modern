1.     The purpose of the Contracts module

The purpose of the contracts module lies within the need for the authorized FIS users to create and maintain vehicle contracts for clients as and when needed on the Fleet Information System (FIS).

It is the assumption that each and every user of the g-FleeT administrative functions on the FIS (Fleet Information System) has received on the job training in the specified field that pertains to his/ her division.

This document will describe how to use the contract module in FIS.

2.     Add a Vehicle Contract

The following section will describe how a vehicle contract should be renewed for a new site.

1    

2    

2.1   After logging on to FIS select the Contracts menu option on the left hand side of the FIS welcome page.

 

 

NOTE: if you don’t see the contracts menu item on the menu list you don’t have access to the contracts section. Please contact the relevant person as specified in the contact detail section at the end of this document.

2.2   Select the Vehicle Contract Maintenance sub-menu option.

2.3   Depending whether you have the GG or the GP number available, select the relevant option.

2.4   Enter the vehicle GG or GP Number and select the submit button.

NOTE: If the vehicle is not on the FIS database yet a “Vehicle not Found” message will appear below. Please contact the relevant person as per the contact details given at the end of this document.

2.5   In order to add a contract for a vehicle, the existing vehicle contract is required to be terminated first. Select the “Terminate current Contract AND Open new one button”.

 

2.6    From the Site drop down box choose the correct site. It is imperative to ensure that the vehicle is loaded onto site where the vehicle will be used otherwise the department will not be able to issue a trip authority for use of the vehicle. If the site does not appear, Sarie Koen should be contacted.

2.7   Click on the Contract type from Contract Type drop down box.

NOTE: The following Contract Types exist that will influence what is display under the Hire type options on the contract screen above. Please see the Contract Type Relationships section later in this document:

Daily: for Hire Pool or VIP vehicles where a daily tariff is charged

Monthly: for permanently allocated vehicles where a monthly fee is charged

Relief: for a substitute for a permanent vehicle that is in the workshop due to an accident, service or repairs. No daily or monthly fee is charged, only a kilometer tariff.

Lease: for vehicles that are leased where a fixed monthly amount is paid (terms and conditions apply).

2.8    Select the Contract start date by clicking on calendar icon à Select the date à Select OK.

NOTE: The start Date is the date the contract will be opened. The contract start date can neither be opened for a date that is in the past not further than 13 days into the future from the current date.

2.9    Select the Target Return Date for the vehicle by clicking on the calendar icon à Select the date à Select OK.

NOTE: The target return date should be in line with the contract type. It is the date or estimated date that vehicle is expected to be returned to g-FleeT. The target return date must be greater or equals to contract start date.

 

2.10                       The start odometer will be auto-populated but it can still be changed if the actual start odometer is higher than the one auto-populated.

2.11                       Enter the Receiver ID

NOTE: The Receiver ID is the valid ID number of the individual who is responsible for collecting the vehicle.

2.12                       Select the Responsibility, Objective and Project codes

NOTE: The Responsibility, Objective and Project codes will be specific to the site for which the vehicle contract is being generated.

2.13                        In the authorization text field enter the Z186 number supplied by the driver collecting the vehicle.

2.14                      

In the note text field enter information as required that may be helpful later on.

2.15                       After verifying the captured information against the “Contract that will be Closed” section at the bottom of the contract page and verifying that all the information is complete select the submit button.

NOTE: If any of the required fields are not completed the system will notify you of the information still required.

2.16                       The Print window will appear twice upon submission of the new contract. Select the relevant printer to print the contract summary page.

 

CONGRATULATIONS! The contract will now be in effect with the information displayed in the contract summary sheet.

3.     Modify a Vehicle Contract

 

This section will describe how a vehicle contract can be modified.

 

 

3    

3.1   Follow steps 1.1 – 1.3 stated above.

3.2   Select “Mod” in order to modify the vehicle contract.

3.3   Select the Target Return Date calendar icon to set the new target return date.

NOTE: The only item on a Vehicle Contract that can be modified from the Contract screen is the “Target Return Date” and the “Notes”. Please contact the contracts department should any other changes be required.

4.     Add a New Contract

The following section will describe how to add a new vehicle contract.

4    

4.1   Follow steps 2.1 to 2.4 for renewing a vehicle contract.

4.2   When the vehicle status of the entered GG/GP number is “New” the following message will appear – select the “Add” button.

 

4.3   The new vehicle confirmation message will display at the top of the new vehicle contract screen

4.4   Follow steps 2.4 to 2.15 under the contract renewal section in order to create the new contract. The only difference is that the Start Odometer will not be populated and there will not be a comparative contract portion at the bottom of the screen.
