User Manual for Taxis Section on the Fleet Information System

 

Purpose of Program

The Purpose of the Taxi program lies within the need for a uniform program for data capturing of all chauffeur services.

 

Term/ Field Analysis

The detail of the required data fields are in most cases self-explanatory but will however be specified.

 

It is the assumption that each and every user of the GGMT Administrative functions on the Fleet Information System has received on the job training in the specified field that pertains to his/ her division.

Fields that is seen on more than one page will not be duplicated in the Term/ Field analysis, as the meanings/ definitions would stay within similar parameters.

 

Service Provider

Identification of the company the specified job will be allocated to.

Class

The class of the transport needed.

Registration

Registration number of the vehicle that have been / will be used for the completion if the job.

Driver Name

Name of the chauffeur that will transport the officials.

Date

Date the transport is needed.

Time

Time the official needs to be collected.

Return Booking

Booking back a trip after completion.

From

The location where the official will depart from.

To

The location where the official will arrive.

Flight Number

The flight number if the official travels by Airplane.

Arrival/ Departure Time

The time the flight will arrive/ depart.

Driver to stay available

Select if the driver needs to be allocated to this official on availability.

JHB International Airport Pick Up

Select if the person need to be picked up at Jhb Intl. Airport

Official Requiring Transport

Name of the official that will be transported.

Tel./ cell of Official requiring Transport

Contact number of the person that will be transported.

Department

Identification of the department the client is from.

Notes

Additional information relevant to the matter.

Name of Transport Manager

Name of the person at the user department responsible for the booking and fleet matters.

Date:

Date the booking has been received.

Tel.

 

Contact number of the transport manager.

Booking Made by

Identify the depot the booking was made with.

Submit

Submits the information to the data base.
